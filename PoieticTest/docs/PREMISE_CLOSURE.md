# Premise-closure register

This register is the mandatory interpretation layer for
`evidence/runs/campaign-001/formal_models.json`. The executable file deliberately
records small discriminators, several of which contain a Boolean field named
`counterexample`. That field means only that the encoded reduced antecedent is
true and its encoded consequent is false. It becomes a counterexample to a
source claim only if this register records the source antecedent as closed.

The grades are exact. `CLOSED FOR PROTOCOL LOGIC` means the source and protocol
quantifiers needed for the mismatch are represented on the declared finite
class. `PARTIAL` means at least one load-bearing source predicate, admissibility
condition, or semantic reading is absent. `CONTROL` means the object is a
wrong-inference guard, not an attack on a source claim. None of these grades
establish actual physical possibility.

The bounded enumerations in `finite_exhaustion.json` are distinct from this
register. Their exact population sizes and outcomes are reproducible, but each
survivor remains qualified by its disclosed finite universe and encoded
well-formedness assumptions. The W3 32-row table is a Boolean ablation over a
structural projection; it does not upgrade `w3_to_a5` to premise-closed status.
