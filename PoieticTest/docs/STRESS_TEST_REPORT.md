## Critical formal findings

### P3.5 has an unresolved cut/domain scope seam

The marked-extension definition requires an embedding of all of
\(K_B(\Sigma)\) at [lines 1132–1140](../subject/spark-poietic-layered-kernel-v1.2-purpose-guarded.md#L1132-L1140).
P3.5's routes protect the selected finite cut \(\beta\) at
[lines 1185–1193](../subject/spark-poietic-layered-kernel-v1.2-purpose-guarded.md#L1185-L1193).
The exact witness is:

\[
K_B=\{a,u\},\qquad \beta=\{a\},\qquad K_{B'}=\{a,b\}.
\]

The reduced set witness makes the cut-level relations true: `a` is retained,
`b` is new, and `u` is destroyed. If the earlier marked-extension definition
requires the embedding domain to remain all of \(K_B\), the conclusion fails.
If “on the cut \(\beta\)” implicitly restricts the embedding domain, it does
not. The checker does not independently interpret every task, route, and
admissibility premise needed to choose between those readings. The warranted
result is therefore a precise scope inconsistency and `UNDERDETERMINED`, not a
premise-closed formal counterexample.

### A W3 path skeleton is insufficient to reconstruct A5

W3 at [line 1231](../subject/spark-poietic-layered-kernel-v1.2-purpose-guarded.md#L1231)
constrains paths through construction, exposure, resistant outcome, award, and
role write. The finite graph projects only that path skeleton. It lets a
constructed candidate traverse the test path while an internal constant
supplies the occupant, the criterion is unlicensed, and permission is closed.
Those same facts prevent the full identification map from validly labelling
the stages as A5 G1–G3. The graph therefore does **not** satisfy P5.3's exact
antecedent.

The 32-row Boolean table likewise fixes `w3_structural=true`; it is not an
enumeration of 32 full W3 identification witnesses. Thirty-one rows fail the
separately encoded A5 facts. This proves the path skeleton alone is
insufficient and makes the meaning of “labels as G1–G4” load-bearing. It does
not formally refute P5.3/P5.6. Status: `UNDERDETERMINED structural-adequacy
criticism`.

### The capstone leaves the selected-successor link ambiguous

At [lines 1432–1454](../subject/spark-poietic-layered-kernel-v1.2-purpose-guarded.md#L1432-L1454),
the prose speaks about “each selected transition” without an explicit
q-specific selection witness. The reduced checker assigns all universal
transition clauses true and supplies no selected edge. It does not, however,
interpret P7.1's extension-existence consequence or establish that an
extension-ready task can coexist with no selectable transition. It therefore
exposes a quantifier/selection ambiguity rather than a full countermodel. A
deterministic repair would add an existential selected, target-essential A5
successor whose joint witness discharges \(R_{P,+}\), \(R_S\),
\(R_X^\Phi\), and W0–W5.

### The protocol negates the wrong quantifier in \(R_G\)

The residue is \(\exists G\,\forall n\) at
[lines 825–841](../subject/spark-poietic-layered-kernel-v1.2-purpose-guarded.md#L825-L841).

[line 1614](../subject/spark-poietic-layered-kernel-v1.2-purpose-guarded.md#L1614).
The exact two-G truth table makes the frozen candidate fail one cut and the
other candidate satisfy all cuts. The residue is true. One failure can refute
only a nominated-G claim; the existential residue requires exhaustive failure
over the admissible architecture class.
