## The one small meaning we fixed

The finite copying-route model compares an allowed error limit with error
numbers. The error numbers were declared to be rational numbers from zero to
one, but the allowed limit itself had no declared type.

The new numbered definition is:

**TH2-D1.** For every finite copying protocol, its allowed error limit is a
rational number from zero to one, including the endpoints.

This is a project-chosen type definition for the next version of the small
model. It is not a theorem from a book or paper, and it does not silently edit
the already sealed SPA-v1 file.

It affects the finite high-fidelity route, the related audit labels, and rows
4 and 6. It does not say that the route succeeds, that a whole agent is
digital, or that a real system reproduces itself.

## Why the definition does not contain the answer

Use the same allowed limit, one half, in two tiny examples. Give each example
exactly one candidate and exactly one witness. In both, make the complete-
protocol check, key, route-data check, implementation check, and every other
route condition true. Keep the same protocol, candidate, witness, key,
implementation, output, and non-error route data. There is no second route
that can rescue the failing example.

- In the passing example, both the protocol error table and the matching
  output-error calculation return one quarter. The finite H route is true.
- In the failing example, both matching error values are three quarters. All
  other route checks stay true, but the terminal bound fails and the finite H
  route is false.

Both examples obey TH2-D1. One can pass the final error check and the other
cannot. So merely saying what kind of number the limit is does not decide
whether the finite route succeeds.

This is only a check on the new type definition. It is not a counterexample
for one of the original twenty rows and says nothing by itself about real
physical self-reproduction.
