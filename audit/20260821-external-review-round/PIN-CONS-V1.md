# Independent review: PIN-CONS-V1
reviewer_model: kimi-k2.7-code
date: 2026-08-21

VERDICT: REVISE

FINDINGS:
- [BLOCKER] PIN_CONS_V1_PLAIN_LANGUAGE.md: the plain-language status line "status: DRAFT_PENDING_REVIEW — nobody has reviewed this yet" directly contradicts the official PIN_CONS_V1_FREEZE.json verification block, which records "independent_mathematical_review": "REVISE (6 findings), repaired; awaiting review verdict on repairs". The plain-language file therefore drops the material caveat that an independent review has occurred and findings have been addressed, violating companion faithfulness and RPS-v1's requirement that the plain-language form retain every material caveat of the official record. The caveat crosswalk likewise omits this review-state condition.
- [MAJOR] PIN_CONS_V1.md / PIN_CONS_V1_FREEZE.json: the status field "DRAFT_PENDING_REVIEW" is inconsistent with the same manifest's verification block, which records a completed review round that returned findings. Per the project status vocabulary used in the anchor records, DRAFT_PENDING_REVIEW means no completed independent review; a record that has received REVISE findings and is awaiting a verdict on repairs is not in that state.
- [MAJOR] PIN_CONS_V1.md §7 / manifest: PIN-CONS-A2 is described as keeping "the N20 denial limb ¬EverettianUniversalClaim_{η′,θ′}(U) available in every finite countermodel." This phrasing is ambiguous: if read as making the denial limb true in every finite countermodel, it would quietly pre-decide part of N20. The record classifies A2 as an acceptance axiom (derivation constraint), but the official wording does not explicitly disambiguate the axiom's effect on derivations/entailments from its effect on model truth values. The plain-language file is clearer; the official text should match it.
- [MINOR] PIN_CONS_V1.md §2: the N20 row and the calculus (63) block are labeled "quoted verbatim," but the quoted text simplifies the anchor notation (e.g., anchor has \mathcal E_{η′} / \mathcal V_{θ′}; record has E_{η′} / V_{θ′}, and uses "∧/∈/∖" instead of "\land/\in/\setminus"). The rendered meaning is preserved, but the byte-for-byte LaTeX source does not match.
- [MINOR] PIN_CONS_V1.md §3: PIN-CONS-D1 characterizes the "old language" whose truth values are preserved as "the vocabulary of Table 1.1 and (12)-(13) over θ-projections." This is too narrow: the frozen calculus also contains definitions such as Linked_{η,θ} in (41), built from (12) components. The pin should explicitly state that the old language includes all frozen calculus definitions over θ-projections, not only the raw certificate vocabulary.

NOTES: I attacked status discipline and companion faithfulness hardest, because those are the only places where the record contradicts itself. Mathematically, the bucket classification is disciplined (definitions vs. acceptance axioms, no hidden bridges), the verbatim anchors are mostly exact modulo notation, and the non-deciding two-structure sketches for D1–D3 are structurally sound. The pinning content itself is conservative and does not appear to pre-decide any N-row, but the status/communication inconsistency must be resolved before the record can pass.
